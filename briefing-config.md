# Morning Briefing Configuration

## Format Preferences

### Markets Section
- **Crude Oil**: WTI (West Texas Intermediate) prices only
  - NOT Brent crude
  - Source: Trading Economics, commodity trackers

### Economic Calendar
- Show **only the main/most important event** for the day
- Skip event counts (e.g., "85 Economic Events")
- Focus on high-impact releases (FOMC, NFP, CPI, PCE, etc.)
- If no major events: note "Light economic calendar"

### Interest Topics
Continue covering:
- AI/Tech
- Oil & Gas
- Rangers
- UFO/UAP
- Egyptology

### Birthdays/Anniversaries
- Pull from Google Calendar when available
- Skip section if none scheduled

## Tone
- Concise but informative
- Emoji for section headers
- Focus on actionable insights over raw data dumps
